# research.sergey-ulyanov.pro

Public research hub for Sergey Ulyanov.

## Current structure

- `/` — research index and project pipeline.
- `/joy-of-phonetics/` — **Global English Accent Evidence Lab**, research protocol / working paper.

## Research status

The Joy of Phonetics / Global English Accent Evidence Lab is a **research protocol plus supporting prototype**, not a validated pedagogical intervention and not a representative atlas of world Englishes.

The newest application modules currently live outside this repository while they are being repackaged as a complete build. They include discovery, audio lab, coaching-session, independent-coding, agreement-analysis, and export workflows. The public page deliberately does not pretend the partial build is production-ready.

## Deployment

This repository is intentionally plain static HTML/CSS so it can be hosted by GitHub Pages, Vercel, Netlify, or any static host. A custom-domain deployment should point `research.sergey-ulyanov.pro` at the chosen host only after the host/project is confirmed.

## Research principles

1. One recording is evidence about one recorded speaker—not a country or group.
2. Source facts, researcher observations, and pedagogical material are separate layers.
3. Uncertainty and disagreement are retained.
4. Observed agreement and Cohen's kappa are reported as distinct statistics.
5. No automated “accent score.”
6. No claims of educational effectiveness until an outcome study exists.
